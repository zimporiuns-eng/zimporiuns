# Checklist de Instalação — VM ARM (zimporiuns-core-01)

## Assim que a VM for criada:
- [ ] Conectar via SSH
- [ ] Atualizar sistema: `sudo dnf update -y`
- [ ] Instalar Docker: script get.docker.com
- [ ] Instalar Code Server (Docker)
- [ ] Configurar Cloudflare Tunnel para code.zimporiuns.com.br
- [ ] Configurar Git privado na VM
- [ ] Migrar Code Server do notebook para a VM
- [ ] Configurar backup automático do volume da VM
